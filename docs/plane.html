Empty candidate cells and infeasibility proofs


Common curvature cancels.
With two edited source counts c and d, squared distance multiplied by 256 is 256(u² + v²) - 32cu - 32dv + b. Every fitting row shares the same quadratic. The remaining affine functions define established power-diagram geometry, not a new search algorithm.
The builder groups identical slopes and clips the unit square by closed exact halfplanes. At most 289 slope groups are possible for this 0..16 count source. All 3,062 original row coefficients are retained. A separate verifier recomputes the intended source, checks feasible vertices and source-supported polygon edges, proves segments and points are maximal, and checks nonnegative integer infeasibility combinations for every empty cell. It does not rerun clipping. The exact total positive area is one; that check alone is not the proof.
Fixed two-coordinate geometry does not cover other observed edits, another mask, natural missingness, plausible image edits or restoration reliability. Source matching is not authentication: callers must supply their intended source independently. The educational verifier is not a parser security boundary.
