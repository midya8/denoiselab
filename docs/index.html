The complete fixed test audit
1,797 original test digits per row, same masks for all methods. Smaller hidden-pixel MSE is better. Neural training used only scattered masks with 32 missing pixels. The other three patterns are predeclared corruption shifts, not validation-tuned models.

One fixed mask per image and case, one training seed. This is descriptive, not a repeated-sample uncertainty estimate. Block masks hide different positions than scattered masks. Equal counts do not isolate a causal effect of mask geometry.


The model has to guess.
The neural network receives 64 erased-pixel values and 64 explicit missing flags, then passes through tanh layers of widths 64, 16 and 64, and a 64-pixel sigmoid output. Manual NumPy backprop trains only on missing-pixel squared error, plus weight decay. Visible pixels are copied at the output.
PCA learns its mean and basis from the same fitting rows. It solves a ridge least-squares problem using only the visible coordinates, not a weak zero-filled projection. Rank and ridge were selected on validation. Nearest neighbor also uses visible coordinates only, with lowest fitting index breaking ties.
The official UCI 3,823 / 1,797 split stays intact. Training is split into 3,062 fitting and 761 validation rows by a fixed class-stratified feature-hash rule; labels are used for that split only. Validation writer identities are unavailable. Test examples were not used to choose architecture, checkpoint, PCA rank, ridge or mask settings.
Established denoising autoencoding and PCA, not a new algorithm or a reproduction of MNIST experiments. No generative sampling, uncertainty calibration, medical restoration, real-world missing-data guarantee, semantic preservation or production claim.
